Документация API

Базовый URL: https://your-domain.com/api
GET /ping

Проверка работоспособности сервера.

Ответ 200
{ "message": "pong" }
GET /objects

Список опубликованных исторических объектов на карте. Все фильтры опциональны — без параметров вернёт все объекты.

Query-параметры
ПараметрТипОписаниеОбязательный
eventTypeIds? int[] Фильтр по типам событий. Передаётся повторением параметра. нет
dateFrom? string Дата от, формат YYYY-MM-DD нет
dateTo? string Дата до, формат YYYY-MM-DD нет
Для нескольких типов событий повторяйте параметр:
?eventTypeIds=1&eventTypeIds=2&eventTypeIds=3
Примеры
// Все объекты
GET /api/objects

// Только типы 1 и 3
GET /api/objects?eventTypeIds=1&eventTypeIds=3

// С диапазоном дат
GET /api/objects?dateFrom=2020-01-01&dateTo=2023-12-31

// Комбинация
GET /api/objects?eventTypeIds=2&dateFrom=2015-01-01&dateTo=2020-01-01
Ответ 200
{
  "objects": [
    {
      "id":              1,
      "title":           "Сражение при Бородино",
      "description":    "Крупнейшее сражение Отечественной войны 1812 года",
      "latitude":        "55.5167",
      "longitude":       "35.8167",
      "eventDate":       "1812-09-07",
      "eventType":       2,
      "previewUrlImage": "https://storage.example.com/sites/1/screenshot.png"
    }
  ]
}

POST /requests

Отправка заявки на публикацию объекта. Тип запроса — multipart/form-data.

Архив должен быть в формате .zip и не превышать 50 МБ.
Внутри архива в корне или на первом уровне вложенности должен быть index.html.
Тело запроса — multipart/form-data
ПолеТипОписаниеОбязательный
title* string Название события, макс. 200 символов да
description* string Описание события да
eventDate* string Дата события, формат YYYY-MM-DD да
eventTypeId* int ID типа события да
email* string Email для обратной связи, макс. 70 символов да
telegramUsername* string Имя пользователя в Telegram (без @) да
archive* file ZIP-архив с сайтом да
Ответ 201
{ "message": "success" }
Ошибки
СтатусПричина
400Архив не .zip или превышает 50 МБ
400Ошибка валидации полей
POST /admin/login

Авторизация администратора. При успехе устанавливает два HttpOnly cookie: access_token (15 мин) и refresh_token (7 дней).

Тело запроса — application/json
{
  "login":    "admin_XxYyZzAa",
  "password": "P@ssw0rd123!"
}
Ответ 200
{ "message": "success" }
// Set-Cookie: access_token=...; HttpOnly
// Set-Cookie: refresh_token=...; HttpOnly; Path=/api/admin/
Ошибки
СтатусПричина
401Неверный логин или пароль
POST /admin/refresh

Обновление пары токенов по refresh_token из cookie. Старый токен инвалидируется.

Тело запроса не нужно — refresh_token читается из cookie автоматически.
Ответ 200
{ "message": "success" }
// Set-Cookie: access_token=...; HttpOnly
// Set-Cookie: refresh_token=...; HttpOnly; Path=/api/admin/
Ошибки
СтатусПричина
401refresh_token отсутствует или невалиден
POST /admin/logout JWT

Завершение сессии. Удаляет сессию из БД и очищает cookie.

Требует валидный access_token в cookie. Тело запроса не нужно.
Ответ 200
{ "message": "success" }
GET /admin/requests JWT

Список всех заявок с пагинацией. Опциональный фильтр по статусу через query-param.

Query-параметры
Фильтр по статусу. Возможные значения: Новая, На проверке, Отклонена, Опубликована
ПараметрТипОписаниеОбязательный
status? string нет
q? string Поиск по названию и ID заявки нет
page? integer Номер страницы (по умолчанию: 1) нет
limit? integer Количество записей на странице, от 1 до 100 (по умолчанию: 20) нет
Примеры
// Все заявки, первая страница
GET /api/admin/requests

// Только новые заявки, страница 2 по 10 записей
GET /api/admin/requests?status=Новая&page=2&limit=10
Ответ 200
{
  "requests": [
    {
      "id":        1,
      "title":     "Сражение при Бородино",
      "status":    "Новая",
      "createdAt": "2026-03-25T10:00:00Z"
    }
  ],
  "total": 45,
  "page":  1,
  "limit": 20
}

GET /admin/history JWT super_admin

Аудит-лог всех действий администраторов по всем заявкам с пагинацией и поиском. Данные об администраторе сохранены на момент действия.

Query-параметры
ПараметрТипОписаниеОбязательный
q? string Поиск по названию заявки, ID заявки, действию и логину модератора нет
page? integer Номер страницы (по умолчанию: 1) нет
limit? integer Количество записей на странице, от 1 до 100 (по умолчанию: 20) нет
Ответ 200
{
  "history": [
    {
      "id":            1,
      "requestId":    42,
      "requestTitle": "Памятник героям ВОВ",
      "action":       "Опубликована",
      "comment":      "",
      "adminLogin":   "admin_XxYyZzAa",
      "adminRole":    "admin",
      "createdAt":    "2026-04-04T12:00:00Z"
    }
  ],
  "total": 87,
  "page":  1,
  "limit": 20
}
Ошибки
СтатусПричина
400Некорректный параметр page или limit
401Невалидный access_token
403Недостаточно прав (требуется super_admin)
