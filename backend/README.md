# Бэкенд для проекта «Россия — страна Героев»

Серверная часть интерактивной карты исторических объектов.
Принимает заявки от пользователей, обрабатывает загружаемые архивы и предоставляет API для администраторов.

---

## Стек

Go · PostgreSQL · MinIO · Redis · Caddy · Docker · n8n (уведомления в Telegram и на e-mail)

---

## API

Полная документация доступна в файле `docs/api.html`.

---

## Требования к загружаемым сайтам

При подаче заявки прикладывается ZIP-архив с сайтом объекта.

**Архив**

- **Формат**: `.zip`
- **Максимальный размер**: 50 МБ
- **Обязательно**: файл `index.html` в корне архива (архивировать содержимое `dist/`, не саму папку)
- При включённом `CLAMAV_ENABLED` архив проверяется антивирусом
- После обработки файлы публикуются в публичный бакет MinIO

**Сайт**

- Только статические сайты — серверный рендеринг не поддерживается (Next.js, Remix и т.д.)
- Никакого бэкенда
- Если используется React Router — только `HashRouter`, `BrowserRouter` не поддерживается
- Для Vite-проектов: указать `base: './'` в конфиге перед сборкой (`npm run build`)
