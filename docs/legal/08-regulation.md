# Положение об обработке и защите персональных данных

Утверждено приказом № [ ] от [дата].

## 1. Общее

1.1. Положение определяет, как [оператор] (далее - Оператор) обрабатывает и защищает персональные данные в информационной системе сайта russia-heroes.ru (далее - Система).

1.2. Положение обязательно для всех, у кого есть доступ к персональным данным: администраторов и модераторов.

1.3. Цели, состав данных, основания и сроки хранения установлены Политикой обработки персональных данных. Положение их не дублирует.

## 2. Состав Системы

| Компонент | Что хранит |
|---|---|
| PostgreSQL | учётные записи, заявки, события, отметки, просмотры, журналы модерации |
| MinIO | ZIP-архивы заявок и опубликованные сайты |
| Redis | коды входа, сессии, хеши IP для ограничения частоты |
| Журналы веб-сервера | IP при ошибках соединения |

Все компоненты размещены на одном сервере: [провайдер, ЦОД, РФ].

## 3. Доступ

3.1. Доступ к панели модерации выдаёт супер-администратор по решению ответственного. До выдачи доступа модератор знакомится с Политикой и Положением и подписывает обязательство о неразглашении.

3.2. Доступ к серверу, базе данных и резервным копиям есть только у лиц из перечня (раздел 7).

3.3. Доступ отзывается в день прекращения работы модератора.

3.4. Модератору запрещено:
- выгружать данные авторов и пользователей из панели и пересылать их;
- обсуждать данные авторов в чатах и почте, кроме переписки с самим автором по заявке;
- передавать свой логин и пароль.

## 4. Меры защиты

- соединение с сайтом и панелью только по HTTPS;
- пароли модераторов хранятся в виде хеша;
- IP-адреса для ограничения частоты хранятся в виде HMAC-SHA256 с ключом, который создаётся при старте процесса и нигде не сохраняется;
- вход на сервер по SSH-ключу, вход по паролю выключен;
- база данных и хранилище не доступны из интернета напрямую;
- действия модераторов с заявками записываются в журнал;
- резервные копии: ежедневный дамп PostgreSQL (сервис backup, том db-backups) и версии файлов в MinIO, хранятся 30 дней; доступ к ним - по разделу 7;
- обновления безопасности ОС ставятся автоматически (unattended-upgrades).

## 5. Уничтожение

5.1. Данные уничтожаются по сроку из Политики автоматически, по отзыву согласия или требованию субъекта - вручную.

5.2. Подтверждение уничтожения - выгрузка из журнала Системы или акт с датой, составом данных, основанием и ответственным. Хранится 3 года.

## 6. Контроль

Ответственный раз в год проверяет, соответствует ли фактическая обработка Политике и Положению, и оформляет результат запиской. Внеплановая проверка проводится после инцидента.
