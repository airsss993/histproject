Компоненты

Компоненты сохраняют одинаковые состояния во всех сценариях. Главное действие залито золотом, вторичное остается контурным, необратимое действие использует приглушенный красный.

Кнопки

Одна залитая кнопка на смысловой блок. Красный цвет нужен только для ошибки и необратимого действия.

Поля

Фильтры

Активное значение видно по золотой рамке, фону и тексту. Цвет не используется как единственный признак.

Статус всегда подписан текстом. Цвет помогает быстро просмотреть список, но не заменяет название.

Карта и карточка

Карта остается главным рабочим полем. Контент появляется рядом с выбранной точкой в компактной стеклянной карточке, не закрывая весь контекст.

Правила применения

Система работает за счет дисциплины. Золото сообщает о выборе и следующем действии. Стекло отделяет рабочий слой от карты. Анимация объясняет изменение состояния.

Использовать

  • Оставлять одно основное действие в блоке.
  • Подписывать статус текстом.
  • Сохранять видимый фокус с клавиатуры.
  • Уменьшать движение по системной настройке.
  • Переносить панели в полноэкранный режим на телефоне.

Не использовать

  • Не заливать золотом большие фоновые области.
  • Не смешивать несколько радиусов на одном уровне.
  • Не передавать смысл только цветом.
  • Не добавлять декоративное движение без действия пользователя.
  • Не помещать длинный текст поверх карты.
Стеклянные поверхности

Размытие используется только там, где под компонентом есть карта или другой содержательный слой. На сплошном фоне остается полупрозрачная поверхность с тонкой верхней кромкой.

Адаптивность

До 640 px верхняя навигация сокращается, панели карты становятся отдельными экранами, пары полей переходят в одну колонку. Минимальная высота активной кнопки - 44 px.

Состояния

Загрузка сохраняет размеры будущего контента. Ошибка называет проблему и дает действие для восстановления. Пустое состояние объясняет, почему данных нет и что можно сделать дальше.
